# 模型与绘图协议概览

POP 2 把图像表示为绘画操作序列。模型依据中文文本、已有图元或二者结合，依次预测后续图元，画布因此保留可编辑的几何内容和绘制顺序。

## 当前公开模型

| 项目 | 数值 |
|---|---|
| 参数数 | 1,004,182,914 |
| Transformer 层数 | 35 |
| 隐藏宽度 | 1536 |
| 注意力头数 / 每头宽度 | 24 / 64 |
| 门控 FFN 隐藏宽度 | 4096 |
| 权重存储精度 | BF16 |
| 总模型上下文 | 1024 个文本或图元记录位置 |
| 文本词表 | 1500 |
| 图元与控制词表 | 7069 |
| 可输出属性词表 | 7054 |
| 原生有效画布 | 512 × 512 |

这里的一个完整图元记录与它的九个离散属性不应混为一谈。属性依次为 x、y、angle、width、height、shape、red、green、blue。完整历史图元把九个属性的嵌入叠加为一个位置；预测当前图元的属性时，使用已知属性和各个尚未预测属性的可学习空嵌入。

训练采用共享压缩历史的多分支注意力机制：不同属性分支共享完整历史，只加入各分支所需的残缺当前图元信息。训练入口提供原模型及相应监督计算，而非用通用文本 GPT 替代。

## 数据与控制记录

绘画按全局、4×4 粗网格、8×8 细网格组织。当前算法的全局普通图元上限为85（背景另计），粗网格每格20、细网格每格10。它们是各阶段/区域的载荷约束，不意味着固定1024上下文可以同时容纳所有区域的最大载荷。

图形坐标为半像素刻度，宽高为四分之一像素刻度，角度为三分之一度刻度，颜色为128档。矩形和椭圆是原生绘画形状；背景使用专用类型。区域起点、永久结束、人工中断和 BOS 具有独立语义，不能渲染成普通图形，也不能把人工暂停替换成永久完成。

模型内图元 BOS 是7068，永久结束是7066，人工中断是7067。属性到 token 的精确映射以 `model/` 的 `token_layout.py` 与 App 模型常量为准。CSV 的字段和 packed 大文件格式以数据生成工具和数据加载器的说明为准。

## 文本与采样

文本使用独立的 SentencePiece 嵌入，并作为图元历史之前的前缀。记录中的文本上限为224，文字和图元位置共同受1024总上下文约束。超长输入应由入口明确报告，不能静默截掉用户内容。

当前 App 的常用起点是 CFG=1、Rényi α=4。CFG=1 表示有文本分支的基线；高于1时按有文本与空文本的输出差异增强条件。Rényi 自适应采样用于确定合法候选范围，再在范围内等概率抽样。默认设置是可调整的采样策略，不是模型权重本身。

App 的上下文超频通过选择保留的历史区域，允许继续绘制更多内容；注意力窗口仍是1024，并未扩展模型的 RoPE 容量。Python研究入口与原生App的功能范围分别在各自README中说明。
