# 发布范围

本目录面向两类使用者：研究者可以构建训练数据、阅读模型定义和监督目标、训练或微调模型；体验者可以安装原生 Windows App，观察与编辑模型的图元生成过程。

包含：

- 正式图像到图元序列工具、对应 GPU shader、依赖锁定和测试源码。
- 与本代权重匹配的模型定义、数据编码/加载、训练核心、检查点与推理入口。
- 原生 App 生产源码、必要的本地依赖补丁、NVIDIA/AMD/CPU后端、构建与安装脚本。
- 当前 Windows 安装包，单独作为 Release 分发附件。
- 公开权重下载器、版本说明和必要许可证。

不包含原始训练图像、全量提示词、训练集缓存、模型/优化器权重、个人存档、密钥、账号令牌、服务器操作脚本、BMC管理、编译缓存、历史实验与视频制作工程。

训练所需数据应由使用者自行准备。使用者需要确认其输入图像、提示词及应用场景的相应使用权。应用的少量内置文本模板属于产品资产，不是全量训练提示词数据集。

源码目录可以提交至已有 GitHub 项目；`distribution/` 下的安装程序作为 Release 附件发布。权重由 Hugging Face 管理。不得把本地整个开发工作区当作发布内容直接提交。
